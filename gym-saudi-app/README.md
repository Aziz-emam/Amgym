# نظام إدارة النادي الرياضي النسائي — المرحلة 1 (محدّثة)

تطبيق ويب متجاوب يعمل على التابلت وويندوز والجوال.

## التشغيل
افتحي index.html في Chrome أو Edge، أو ارفعي المجلد على GitHub Pages.

## التحديثات الأخيرة
- علامة الريال (ر.س) بدل الدولار
- مدد الاشتراك: يوم / نصف شهر (15 يوم) / شهر وأكثر — مع خيار تحديد أيام أو أشهر من التسعير
- البحث في الحضور بالاسم أو الرقم + زر مسح الكاميرا للباركود
- أزرار سريعة في الصفحة الرئيسية (حضور، متواجدات، اشتراك جديد)
- اسم النادي في الهيدر يحوّل للصفحة الرئيسية
- لوحة ألوان كاملة لاختيار الثيم
- رسالة واتساب نص فقط بدون باركود
- البيانات تُحفظ على الجهاز + تصدير/استيراد كامل لأي جهاز آخر
