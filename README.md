# نظام إدارة النادي الرياضي النسائي — النسخة التجريبية (المرحلة 1)

تطبيق ويب متجاوب يعمل على التابلت وويندوز وأي متصفح حديث.

## طريقة التشغيل
1. فك الضغط عن الملف.
2. افتحي ملف index.html مباشرة في المتصفح (Chrome أو Edge مفضلين).
3. أو ارفعي المجلد على GitHub Pages.

لا يحتاج سيرفر ولا تثبيت. البيانات تُحفظ محلياً في المتصفح (localStorage).

## المميزات المنفذة
- لوحة تحكم مع إحصائيات وتنبيهات
- إدارة المشتركات (إضافة / تعديل / حذف / تجديد)
- دفع نقدي أو تحويل بنكي مع تعبئة المبلغ تلقائياً حسب نوع الاشتراك والمدة
- توليد QR Code لكل عضوية
- إرسال رسالة واتساب جاهزة (تفتح واتساب الجهاز بدون رسوم API)
- الحضور والانصراف برقم العضوية أو QR
- صفحة المتواجدات حالياً مع مدة التواجد
- نظام التجاوز الذكي (يحسب فقط عند الحضور بعد انتهاء الاشتراك)
- تسعير الاشتراكات قابل للتعديل بالكامل من الواجهة
- الموظفات + الرواتب (تُسجل تلقائياً كمصروف)
- المصروفات مع تصنيفات
- التقارير اليومية والمخصصة
- الورديات (فتح / إغلاق مع تقرير تلقائي)
- إعدادات: اسم النادي، اللوجو، الثيمات (4 ألوان + داكن/فاتح)، رسائل واتساب، نسخ احتياطي
- توقيع AM ثابت أسفل اليسار يتغير لونه مع الثيم

اللهجة: الواجهة بالكامل بأسلوب سعودي واضح ومريح.

المرحلة القادمة: طباعة بطاقة عضوية، صلاحيات، PWA.
